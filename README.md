# موقع غياث عبد الرزاق — مهندس تصميم ميكانيكي

موقع شخصي (Portfolio + CV رقمي) لمهندس تصميم ميكانيكي، مبني بـ HTML5 و CSS3 وأقل قدر ممكن من JavaScript. لا يعتمد على أي مكتبات خارجية أو أدوات بناء (Build Tools)، وجاهز للنشر مباشرة على GitHub Pages.

## بنية الملفات

```
.
├── index.html                          # الصفحة الرئيسية (كل الأقسام)
├── style.css                           # كل الأنماط
├── script.js                           # جافاسكريبت خفيف جداً (قائمة الموبايل + زر العودة للأعلى + تأثير ظهور عند التمرير)
├── .nojekyll                           # يمنع GitHub من معالجة الموقع كـ Jekyll
└── assets/
    ├── cv-ghaith-abdulrazzaq.pdf       # ملف السيرة الذاتية (يجب استبداله بالملف الحقيقي)
    └── images/
        ├── project-1.svg ... project-6.svg   # صور بديلة (Placeholder) للمشاريع
```

## ما يجب تعديله قبل النشر النهائي

1. **السيرة الذاتية**: استبدل `assets/cv-ghaith-abdulrazzaq.pdf` بملفك الحقيقي بنفس الاسم، أو غيّر الاسم وحدّث الرابط في `index.html` (يوجد مرتين: في قسم Hero وفي قسم تحميل السيرة الذاتية).

2. **صور المشاريع**: استبدل ملفات `assets/images/project-1.svg` إلى `project-6.svg` بصور حقيقية لمشاريعك (يفضّل بصيغة `.jpg` أو `.webp` بحجم مضغوط لا يتجاوز 150-200 كيلوبايت لكل صورة للحفاظ على سرعة التحميل)، وحدّث الامتداد في `index.html` إذا غيّرت الصيغة.

3. **بيانات التواصل**: في قسم `#contact` بداخل `index.html`، حدّث البريد الإلكتروني ورقم الهاتف ورابط LinkedIn ليطابق بياناتك الحقيقية.

4. **نموذج التواصل**: النموذج الحالي يستخدم `action="https://formspree.io/f/your-form-id"` كمثال. لتفعيل استقبال الرسائل فعلياً:
   - أنشئ حساباً مجانياً على [Formspree](https://formspree.io) (أو أي خدمة مشابهة).
   - استبدل `your-form-id` بالمعرّف الذي يمنحك إياه الموقع.

5. **النصوص**: جميع النصوص (الخبرات، التعليم، الشهادات) هي نصوص نموذجية توضيحية — راجعها وعدّلها لتطابق سيرتك الفعلية.

## النشر على GitHub Pages

1. أنشئ مستودعاً (Repository) جديداً على GitHub.
2. ارفع كل الملفات (`index.html`, `style.css`, `script.js`, `.nojekyll`, ومجلد `assets`) إلى المستودع.
3. اذهب إلى **Settings → Pages**.
4. تحت **Branch**، اختر `main` والمجلد `/ (root)`، ثم اضغط **Save**.
5. بعد دقيقة أو دقيقتين، سيكون موقعك متاحاً على رابط مشابه لـ:
   `https://username.github.io/repository-name/`

## ملاحظات تقنية

- التصميم Mobile First بالكامل، ويستخدم Flexbox و CSS Grid فقط دون أي مكتبة CSS خارجية.
- جافاسكريبت محدود بثلاث وظائف فقط: فتح/إغلاق قائمة الموبايل، إظهار/إخفاء زر العودة للأعلى، وتأثير ظهور خفيف للعناصر عند التمرير باستخدام `IntersectionObserver` (وهو أخف وأسرع من مستمعي `scroll` التقليديين).
- الموقع يحترم خاصية `prefers-reduced-motion` لتعطيل الحركة لمن يفضل ذلك.
- في حال تعطّل JavaScript تماماً، يبقى كل المحتوى ظاهراً بسبب آلية `no-js` المطبّقة على عنصر `html`.
- الخطوط (`Tajawal` و`JetBrains Mono`) تُحمَّل من Google Fonts مع `preconnect` لتقليل وقت الاستجابة.
